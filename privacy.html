Who this covers

This policy covers a personal tool written and used by one person, for their own mailboxes. It is not a product, has no customers and has no other users. This site does not use cookies, analytics or tracking, and collects nothing from visitors.

What it accesses

With the owner's consent it uses two Google permissions: managing email filters, and managing labels. It does not request access to the content of any email, and it cannot read, send, move or delete messages.

What it does with that access

It creates, lists and deletes the owner's own Gmail filters and labels so that they match a rules file the owner keeps. Nothing is collected, sold, shared with anyone, or used for advertising or training any model.

Where credentials are kept

The sign-in token is stored only on the owner's own computer, in a private file readable only by the owner. It is not uploaded anywhere.

Withdrawing access

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions), after which the tool can no longer reach the account.

Changes

If this policy changes, the date above will change with it.
